# 중앙 관리자 사용 안내

## 이 컴퓨터에서 시작하기

### v4.5.1부터: 버튼으로 열기 (권장)

1. SiteFlow의 **관리자 웹사이트 열기**를 누릅니다.
2. 처음 한 번만 화면에서 관리자 비밀번호를 만들고 기록 연결에 동의합니다.
3. 자동으로 열린 웹사이트에서 설정한 비밀번호로 로그인합니다.

다음부터는 같은 버튼을 누르고 로그인하면 됩니다. 별도 서버 실행, 주소 입력,
연결 키 복사는 필요 없습니다. 프로그램을 닫으면 로컬 관리자 서버도 종료됩니다.
외부 서버 수동 설정은 상단 **관리자 > 외부 서버 연결 (고급)**에 있습니다.
다른 컴퓨터와 통합하는 공용 서버는 아직 구성되지 않았습니다.

### 소스에서 별도로 서버를 실행하는 경우

1. 프로그램 소스 폴더의 `admin-start.bat`을 실행합니다.
2. 처음에는 관리자 비밀번호를 두 번 입력합니다. 14자 이상이어야 합니다. 입력 중 문자가 보이지 않는 것은 정상입니다.
3. 브라우저에서 `http://127.0.0.1:8787`을 열고 로그인합니다. 서버 실행 창을 닫으면 관리자 웹사이트도 중지됩니다.
4. `admin-connection-key.bat`을 실행하고 연결 키 복사 버튼을 누릅니다.
5. 새 SiteFlow의 `중앙 관리자 연동`에서 서버 주소, 컴퓨터 이름, 연결 키를 입력하고 전송에 동의합니다.

처음 연결하면 기존 사이트의 현재 상태와 Cloudflare 계정을 전송합니다.
이후 프로그램이 저장하는 상태 변화가 기록됩니다. 예전 원본 로그 전체를 가져오는 기능은 아닙니다.
서버 연결 실패 시 암호화된 기록을 보관하고 30초마다 재시도합니다.
관리자 화면의 새로고침 버튼으로 확인할 수 있습니다.

## API 토큰 확인

계정을 선택하고 관리자 비밀번호를 다시 입력한 뒤 토큰 보기를 누릅니다.
30초 뒤 화면에서 지워지며, 복사한 클립보드 내용은 자동으로 지워지지 않습니다.

## 수정 재배포

Cloudflare 계정을 선택하고 기존 프로젝트명을 정확히 입력한 뒤 수정한 ZIP을 선택합니다.
확인 창에서 계정과 프로젝트를 확인하면 기존 사이트 전체를 교체합니다.
사이트 주소는 Cloudflare에서 조회한 실제 주소를 사용하며 HTML·사이트맵·robots 주소를 보정합니다.
기존 소유확인 HTML도 ZIP에 포함해야 합니다. 이전 ZIP을 자동 백업하지 않으므로 원본을 보관하세요.
관리자 재배포는 새 사이트 생성이나 다른 계정으로 자동 전환을 하지 않습니다.

## 다른 컴퓨터 연결

현재 주소는 이 컴퓨터에서만 접속할 수 있습니다. 다른 컴퓨터를 연결하는 작업은 아직 완료되지 않았습니다.
공용 HTTPS 서버 또는 별도 보안 연결 구성이 필요하며, 서버 비용이나 도메인을 임의로 결제하지 않았습니다.
서버 구성 방법은 같은 폴더의 README.md에 있습니다. HTTP 포트를 인터넷에 직접 공개하지 마세요.

관리자 데이터는 `%LOCALAPPDATA%\SiteFlowAdmin`에 저장됩니다.
프로그램의 일반 계정·ZIP·네이버 쿠키 저장소는 변경하지 않습니다.
